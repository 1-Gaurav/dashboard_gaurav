 📊 Simple Dashboard

A **responsive dashboard UI** built using **HTML, CSS, and JavaScript**.  
This project is only the **frontend** and demonstrates a basic dashboard layout with sidebar, navbar, and content area.

 🚀 Features
- Sidebar navigation menu
- Top navigation bar (header)
- Cards/sections to display data
- Responsive layout (works on desktop & mobile)
- Simple styling with CSS (can be extended with Bootstrap or custom design)

---

 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
